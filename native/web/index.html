USA Melee (GALE01), ISO or CISO. Read locally in a worker; no upload or bundled game assets.

Starting WebGPU…

This is a character animation prototype, not a playable game. It reuses the native port’s disc, DAT, texture, skeletal animation, skinning, and visibility code. Rendering approximates a single texture layer and lighting; complete GX/TEV, material animation, gameplay, input, audio, and saves are not ported yet.
