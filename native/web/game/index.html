Melee Browser — development build

Select your own Melee USA revision 2 ISO or CISO. The game reads this file locally; it is not uploaded.

Both players need the same disc file and browser build. Online play uses a fresh memory card and the Player 1 keys or first gamepad on each device.

Keep this tab visible while playing. Leaving the tab ends the online session.

Offline browser port in development. Saves use this browser’s local storage. Export a backup to keep them elsewhere.

Player 1
Move: WASD · A/B: J/K · Jump: U/I
Grab: O · Shields: Q/E · Start: Enter

Player 2
Move: arrows · A/B: numpad 1/2 · Jump: numpad 4/5
Grab: numpad 6 · Shields: numpad 7/9 · Start: numpad Enter

Standard gamepads use the first two connected controller slots. Press a controller button to make it visible to the browser. Reload the page to restart or change discs.
